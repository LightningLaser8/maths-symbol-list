# Maths Symbol List
Progressive Web App providing a simple searchable list of commonly used mathematical and logical symbols.  
Provides an easy way to copy symbols to the clipboard, or find related symbols.  

Registers a protocol handler, so links to symbols can be provided as `web+sym:<name>`, where `<name>` is the name of the symbol (case sensitive), like `delta` (δ) or `pi-upper` (Π).  
For example, `web+sym:integral` links to the integral symbol (∫) and gives the user a list of related symbols, like summation (∑) and N-ary product (∏).
